# Regex-детектив

## Правила
Игрок расследует преступление, решая задания
с регулярными выражениями.

Каждый раунд содержит:
- Условие и примеры
- Скрытые проверки
- Подсказку при необходимости
- Улику за правильное решение

## Запуск
python main.py

## Тестирование
python test_game.py

## Главы
1. Бюро пропусков — 2 раунда (re.fullmatch)
2. Архив переписки — 2 раунда (re.finditer)
